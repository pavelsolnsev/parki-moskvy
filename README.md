# Парки Москвы — вёрстка главной страницы

**Демо:** https://pavelsolnsev.github.io/parki-moskvy/
**Готовая сборка:** папка [`public/`](public) — `index.html` открывается прямо с диска, без сервера.

## Что сделано

- Адаптивная вёрстка главной по макету: шапка, слайдер, «В центре внимания», увлечения, афиша с фильтрами, карта парков, новости, журнал, подписка, партнёры, подвал.
- **Шапка, хлебные крошки и подвал физически отделены от контента.** Они подключаются общим шаблоном [`default.html`](.distr/templates/default.html), а страница заполняет только `<main>`. Крошки задаются страницей и выводятся между шапкой и `<main>`, вне контента.
- **Только проверенные плагины:** jQuery 4, Swiper 14, Select2 4.1 (все селекты — на select2).
- **Открытые события:** штатные события Swiper и Select2, плюс свои `CustomEvent` у компонентов (дата и фильтры афиши, карта, меню, подписка) и глобальный `App` API для своих скриптов. Список событий и примеры — в [`docs/plugins.md`](docs/plugins.md).
- **Доступность:** семантическая разметка и landmarks, ссылка «к основному содержанию», видимый фокус, управление с клавиатуры, aria-атрибуты, подписи для экранных дикторов.
- **SEO:** мета-теги, Open Graph, микроразметка Organization, WebSite и BreadcrumbList, `robots.txt`.
- **Кроссбраузерность:** Safari/iOS 15.4+, актуальные Chrome, Edge, Firefox, Яндекс Браузер; префиксы через Autoprefixer.
- **Оптимизация:** изображения в WebP, ленивая загрузка, сжатые картинки и SVG; фоновые видео слайдов в AV1 и H.264 (облегчённые версии для телефонов, превью-кадр, без звука, не загружаются в режиме экономии трафика, есть кнопка паузы).

## Структура

```
.distr/templates/default.html   каркас страницы: шапка, крошки, <main>, подвал
.distr/pages/                   страницы
.distr/blocks/<блок>/           block.php (Nunjucks), _style.scss, script.js, img/
public/                         готовая сборка
docs/plugins.md                 плагины, события, JS API
```

## Сборка

```
npm install
npm run build        сборка в public/
npm run build:prod   минифицированная сборка
npm start            сборка + локальный сервер с live reload (нужен PHP в PATH)
```
